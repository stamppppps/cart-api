# Cart API

Backend API สำหรับระบบ Shopping Cart พัฒนาด้วย **Node.js + Express + TypeScript** เชื่อมต่อกับ **Supabase PostgreSQL** และใช้ **JWT (JSON Web Token)** สำหรับ Authentication

โปรเจกต์นี้เป็น Backend API สำหรับจัดการผู้ใช้งาน สินค้า ตะกร้าสินค้า คำสั่งซื้อ และการชำระเงิน

---

## 📌 Technology Stack

* **Node.js**
* **Express.js**
* **TypeScript**
* **Supabase PostgreSQL**
* **Supabase JS**
* **JWT (JSON Web Token)**
* **CORS**
* **dotenv**
* **tsx**

# 4. Environment Variables

## SUPABASE_URL

URL ของ Supabase Project

ตัวอย่าง:

```env
SUPABASE_URL=https://your-project.supabase.co
```

สามารถดูได้จาก:

```text
Supabase
→ Project Settings
→ API
→ Project URL
```

---

## SUPABASE_SERVICE_ROLE_KEY

ใช้สำหรับ Backend เชื่อมต่อ Supabase Database

```env
SUPABASE_SERVICE_ROLE_KEY=your-secret-key
```

> ⚠️ ห้ามนำ Key นี้ไปใส่ Frontend
> ⚠️ ห้าม Commit `.env` ขึ้น GitHub
> ⚠️ ห้ามโพสต์ Key ใน GitHub, Discord หรือช่องทางสาธารณะ

---

## JWT_SECRET

ใช้สำหรับสร้างและตรวจสอบ JWT

ตัวอย่าง:

```env
JWT_SECRET=your-secret-key
```

สามารถตั้งเป็น Secret ที่เราสร้างเองได้

ตัวอย่าง:

```env
JWT_SECRET=cart-api-secret-2026
```

สำหรับ Production ควรใช้ Secret ที่มีความปลอดภัยสูงและไม่ควรเผยแพร่

# 6. Create Users Table

รัน SQL:

```sql
create table users (
  user_id bigint generated by default as identity primary key,
  username varchar(50) not null unique,
  password varchar(255) not null,
  role varchar(20) not null default 'CUSTOMER',
  created_at timestamp with time zone default now(),

  constraint users_role_check
    check (role in ('CUSTOMER', 'ADMIN'))
);
```

# 🔐 Authentication

ระบบใช้:

**JWT (JSON Web Token)**

Flow:

```text
Client
  │
  │ username + password
  ▼
POST /auth/login
  │
  ▼
Backend
  │
  │ ตรวจสอบ User
  ▼
Supabase
  │
  │ User ถูกต้อง
  ▼
Backend
  │
  │ สร้าง JWT
  ▼
Client
  │
  │ access_token
  ▼
Protected API
```

---

# 11. Login API

## Endpoint

```http
POST /auth/login
```

URL:

```text
http://localhost:4000/auth/login
```

### Request Body

เลือก:

```text
Body
→ raw
→ JSON
```

ใส่:

```json
{
  "username": "customer01",
  "password": "123456"
}
```

---

## Successful Response

```json
{
  "message": "Login successful",
  "user": {
    "user_id": 1,
    "username": "customer01",
    "role": "CUSTOMER"
  },
  "access_token": "eyJ..."
}
```

ค่า:

```text
access_token
```

คือ JWT ที่จะใช้เรียก Protected API

---

# 12. JWT Protected API

หลัง Login สำเร็จ จะได้รับ:

```text
access_token
```

นำ Token ไปใช้กับ API ที่ต้อง Login ก่อน

ตัวอย่าง:

```http
GET /cart
```

URL:

```text
http://localhost:4000/cart
```

---

## Authorization

ใน Postman ไปที่:

```text
Authorization
→ Type: Bearer Token
```

นำ `access_token` ที่ได้จาก Login มาใส่:

```text
eyJhbGciOiJIUzI1NiIs...
```

Postman จะส่ง:

```http
Authorization: Bearer eyJ...
```

---

## Successful Response

```json
{
  "message": "You can access cart",
  "user": {
    "user_id": 1,
    "username": "customer01",
    "role": "CUSTOMER"
  }
}
```

แสดงว่า JWT ถูกต้องและสามารถเข้าถึง Protected API ได้

---

# ❌ Authentication Errors

## ไม่มี Token

Request:

```http
GET /cart
```

โดยไม่มี Authorization Header

Response:

```json
{
  "message": "Access token is required"
}
```

Status:

```text
401 Unauthorized
```

---

## Token ไม่ถูกต้อง

ถ้า Token ผิดหรือหมดอายุ:

```json
{
  "message": "Invalid or expired token"
}
```

Status:

```text
401 Unauthorized
```
